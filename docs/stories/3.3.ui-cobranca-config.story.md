# Story 3.3 — UI: dados de cobrança no MedicoForm + ViaCEP + tela de Configurações

## Status
Ready for Review

## Story
**As a** operador/admin,
**I want** preencher os dados de cobrança do médico (com autofill de endereço por CEP) e
configurar os defaults comerciais do escritório,
**so that** os médicos fiquem prontos para emissão sem digitação manual excessiva nem erro.

## Acceptance Criteria
1. `MedicoForm` ganha uma seção **"Dados de cobrança"** (colapsável) com: tipo (PF/PJ), documento
   (máscara conforme tipo), nome/razão social, e-mail, CEP, logradouro, número, complemento,
   bairro, cidade, UF.
2. Ao completar um CEP válido, os campos logradouro/bairro/cidade/UF são preenchidos via **ViaCEP**
   (`https://viacep.com.br/ws/{cep}/json/`), com tratamento de CEP inexistente.
3. A seção é **opcional**: salvar médico sem cobrança continua funcionando (preserva
   auto-descoberta); campos parciais são validados pelo schema de 3.1 ao enviar.
4. Overrides comerciais por médico (vencimento/multa/juros/desconto) editáveis na mesma seção
   (opcionais; vazio = herda o global).
5. Nova tela/aba **Configurações de Cobrança** (admin) para editar `config_cobranca`
   (dias_vencimento, multa, juros, desconto), lendo/gravando via API.
6. Indicação visual de "cobrança pendente" reaproveita a semântica de `cobrancaCompleta`
   (ex.: badge no card/lista do médico).
7. `typecheck`, `lint`, `test` verdes; segue o design system atual (tokens `cc-*`, tema dark/light).

## Complexidade e Riscos
- **Complexidade:** L (~5 pontos). Maior story: form + máscara + ViaCEP + tela de config + CSP.
- **Escopo OUT:** emissão/gateway (3.2) e importação CSV (3.4).
- **Riscos:**
  - CSP bloquear o fetch do ViaCEP se `https://viacep.com.br` não for adicionado ao `connect-src`.
    *Mitigação:* task explícita de CSP em `next.config.mjs`.
  - Indisponibilidade/timeout do ViaCEP. *Mitigação:* degradar com graça — permitir digitação
    manual do endereço; não bloquear o salvamento.
  - Autorização da tela de Config (só admin). *Mitigação:* `requireRole` no PUT + esconder no nav.
- **DoD:** AC 1-7 + testes verdes + File List completa.
