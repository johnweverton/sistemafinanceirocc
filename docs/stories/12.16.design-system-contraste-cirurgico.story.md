# Story 12.16 — Design system nas telas de contabilidade e contraste cirúrgico

## Status
Ready

## Story
**As a** operador que usa as telas de clientes contábeis,
**I want** que as tabelas e avisos usem o design system já existente, e que o texto informativo
tenha contraste AA,
**so that** a área de contabilidade pare de reimplementar o que o resto do sistema já define.

## Contexto
Fase 3 BAIXA do épico `docs/architecture/epic-sanitizacao-emissoes.md`. Cobre R-18, **R-22 opção
(a)** (G-24, G-26, G-44), decisão **D4** (restrição de escopo: token intocado).

**[DEP]** 12.1 (para a parte oportunística dos 4 modais restantes).

## Acceptance Criteria
1. As 3 tabelas (`DetalheCliente.tsx:127,:156`, `FaturamentoEEmissao.tsx:180`) usam
   `.data-table`.
2. O aviso de reajuste anual (`DetalheCliente.tsx:116-121`) usa `.alert-warning` (não
   `alert-error` vermelho com `role="alert"`, que é tom de erro para um aviso).
3. Os pontos de G-44 (`LoteContabilidadeDialog.tsx:167,:172`, `GerarExecucao.tsx:102`,
   `FaturamentoEEmissao.tsx:110`, `NovaExecucao.tsx:742,:1028`) usam `cc-ink-2` (6,98:1) no lugar
   de `cc-muted` (3,70:1).
   **[AJUSTE @po 2026-08-25]** `NovaExecucao.tsx:742` já é resolvido por **12.9** (AC 1), que tira
   aquele aviso de `text-xs text-cc-muted` e o promove a aviso de peso proporcional — 12.9 é Fase 1
   e fecha antes desta. Ao chegar aqui, **verificar** o ponto: se `cc-muted` já não estiver lá, o
   item está cumprido, **não** rebaixar o aviso de volta para texto informativo só para aplicar
   `cc-ink-2`. Restam então 5 pontos, não 6. O critério de aceite é "nenhum dos pontos de G-44
   permanece em `cc-muted`", não "6 substituições feitas".
4. **Restrição dura (D4):** `docs/design-system.md` e as variáveis CSS **não são tocados** — a
   troca é pontual, arquivo por arquivo, nos pontos citados.
5. Oportunístico (não bloqueante): migrar para `<Modal>` os 4 modais restantes fora do caminho de
   emissão (`DreManager.tsx:102`, `LinkPublicoBI.tsx:53`, `ExtratoManager.tsx:116,:227`), fechando
   a métrica **10 cascas → 1 componente**.
6. Débito `DEB-12.1-A` (achado no gate da 12.1): `<Modal>` não trava o scroll do `<body>` — usar a
   pilha `pilhaDeModais` que já existe para bloquear scroll do fundo enquanto qualquer modal está
   aberto (~10 linhas). Julgamento do `@qa`: `aria-hidden` no conteúdo de fundo é redundante
   (`aria-modal="true"` já é o mecanismo ARIA 1.2 usado pelos diálogos pré-existentes do repo) e
   travar o scroll não é critério WCAG 2.1 AA — é UX, não conformidade — mas fecha aqui, não em
   story própria.
